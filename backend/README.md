# Aster Financials API — V1 foundation

Development/sandbox backend foundation for the Aster Android app.

## Current endpoints
- `GET /health`
- `GET /api/v1/system/status`

## Next
Authentication, account state, ledger posting, sandbox wallet flows, market-data adapter, sandbox trading engine, staking/rewards, admin APIs, and Android API integration.

Real-money functionality must remain disabled until appropriate security, custody, market-data/settlement, compliance and regulatory controls are completed.
